# Report B, round 2: rail + card for Applications and the workspace (2026-11-16)

## What changed

**Applications and Offers on the rail**

- New `apps/web/src/features/applications/components/applications-section.tsx`: `ApplicationsSection` wraps
  `SectionLayout` (title "Applications"). Rail: List, Board, Insights, Calendar (`?view=`, each with a `current`
  override), then a group hairline and Offers (`/dashboard/applications/offers`, `count` = saved offers). Phones leave
  out Board and Calendar (the page already falls back to the list there). `APPLICATION_VIEWS` now lives here.
- `routes/dashboard/applications/index.tsx`: renders inside `ApplicationsSection` instead of `Page`. The view `Segment`
  and the header's "Compare offers" button are gone; Import/Export and Save job stay in the header; search sits on
  the toolbar row (left-aligned now that it's alone). A rail switch still animates the new view in and closes the open
  application (detected from the view changing, since the rail is links, not a `Segment` callback). The unused
  `setSearch` is removed.
- `routes/dashboard/applications/offers.tsx`: renders inside `ApplicationsSection` (`view={null}` marks Offers
  current); back link dropped.

**Workspace on `SectionLayout`** (`features/career/workspace/shell.tsx`)

- Rail with all 7 tabs: Fit, Apply | Prepare, Practice, Debrief | Messages, Saved (hairlines via `group`; the group
  names are plain code-only strings, since the rail doesn't show them). Icons: list-checks, note-pencil,
  clipboard-text, microphone, chat-centered-text, envelope-simple, clock-counter-clockwise. Labels from `tabLabel`.
  The inner Interview `Segment` is gone. Every tab URL works; `WORKSPACE_TABS` unchanged.
- Badges at the icon corner, same size as the rail's counts (`RailBadge`): Prepare = countdown in narrow units via
  `Intl.NumberFormat` (`18m`, `3h`; warning colour in the last hour; only within a week; no new msgids), Messages =
  accent unread, Saved = `count`.
- In the card: the job header (back link, title, stage, Ask the coach), then the panel; from 1280px the details
  (next step, documents, notes) are a 300px column on the right of the panel, narrower they fold into "Details" above
  it. Header lost its own padding (the card has it). The skeleton renders inside the same rail + card.
- `TabBadge` replaced by `RailBadge`; the `INTERVIEW_TABS` helpers removed.

**Empty states**: `fit.tsx` and `prepare.tsx` (`Notice`) no longer wrap actions in a vertical container: the button is
a direct sibling, and the privacy/credits notes go on their own row under it (`basis-full`). The coach sheet already
uses `media={<HeadingOrb />}` (principal's change, kept).

**Tests** (`workspace/shell.test.tsx`): the rail test now expects the 7 items in order, 2 hairlines, Practice current
on `practise`; the countdown test looks on Prepare. The "no switch on other sections" test is removed (no switch).
