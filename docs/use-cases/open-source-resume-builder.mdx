Rezumi is a hosted resume and career workspace with a free plan and planned paid passes.
The source repository is restricted. Earlier descriptions of public source access and unrestricted hosted features are no longer current.

Data portability remains available on every plan: download resumes as JSON or export your account data.
See [plans](/use-cases/free-resume-builder), [data export](/guides/exporting-your-data) and
[component license notices](/legal/license). Retained licenses do not promise public access to the hosted code.
