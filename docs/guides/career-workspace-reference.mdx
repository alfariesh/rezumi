## Where things live

| Place                                                   | Purpose                                                                                                          |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Home**                                                | Notifications, discovered roles, your next interview, recent documents and schedules.                            |
| **Coach** in the top bar                                | Conversations across your search, in a panel beside the page (a sparkle icon on a phone).                        |
| **Profile → Details**                                   | [Name, headline, photo, contact details and links](/guides/using-your-profile) your documents take.              |
| **Profile → Career**                                    | Summary and career entries your documents take; **Bring what you have** fills them while empty.                  |
| **Profile → Facts**                                     | Statements about your experience, sources, corrections and coaching controls.                                    |
| **Profile → Stories**                                   | Situation, Task, Action, Result and Reflection with supporting facts.                                            |
| **Profile → Preferences**                               | Target roles, places, search countries, salary and work preferences.                                             |
| **Jobs**                                                | [Search current openings](/guides/searching-for-jobs), check your fit, then track one or tailor a resume for it. |
| **Applications → All**                                  | Your applications as a list, board or calendar (the switch beside the search).                                   |
| **Applications → Insights**                             | How far applications get, how often people reply and where applications come from.                               |
| **Applications → Offers**                               | **Offers**: two saved offer versions and unanswered questions.                                                   |
| **Applications → application details → Open workspace** | Work on one job.                                                                                                 |
| **Settings → AI providers**                             | AI connections and default provider.                                                                             |
| **Settings → General**                                  | Account timezone and display preferences.                                                                        |

## Application workspace sections

| Section      | Main action                                 | What stays with the job                                                         |
| ------------ | ------------------------------------------- | ------------------------------------------------------------------------------- |
| **Fit**      | **Check fit**                               | Requirements, their origin, supporting evidence and preference checks.          |
| **Apply**    | **Draft**, **Tighten**, **Mark as applied** | Editable form answers, backing facts, checklist and submitted answer snapshots. |
| **Prepare**  | **Plan my preparation**                     | Timed plan, short briefing, stories and questions for an interview.             |
| **Practice** | **Hear it**, **Get feedback**               | Typed or spoken attempts and feedback.                                          |
| **Debrief**  | **Review my answer**                        | A recalled real interview answer, observations and practice priorities.         |
| **Messages** | **Read it for me**                          | Employer message, suggested reply and reviewable application changes.           |
| **Saved**    | **Open in…**                                | Earlier generated material and saved offer or answer versions.                  |

The workspace opens on the section that suits the application's stage and interview timing. Select another in the menu on the left to work elsewhere; on a phone the menu is a row of chips above the page. The context column shows the next step, people, documents and notes for the job; on smaller screens they fold under **Details**.

The native iPhone app opens the relevant tab through a task-named action in application details, such as **Prepare application** or **Draft a follow-up**. Workspace arrows reveal additional tabs when the strip is wider than the screen. The native app still calls the Profile's facts, stories and preferences **Knowledge**, with inline **Facts**, **Stories** and **Preferences** choices. [Native iPhone controls](/guides/editing-on-mobile#native-iphone-app) also explains unsynced recovery and form dismissal.

## Saved versions

Generated fit checks, briefings, practice feedback, debriefs and message reviews are saved. Drafted or tightened form answers first need **Accept**; answers are copied into Saved when recorded through **Apply → Mark as applied**.

**Saved** lists items newest first and offers filters by type. Removing the last item in a selected type returns the list to All. **Open in…** opens an earlier version read-only in its section; **Back to current** returns to current work. Offer items open in **Offers**.

Changes to your facts, stories, preferences, the posting or documents can make an old result out of date. An old version records what was produced then; it is not automatically rewritten.

Sent resume and letter versions are document snapshots shown under **What you sent**. They are separate from the latest editable document and remain accessible while that document is in Trash. See [Managing an application](/guides/managing-an-application#seeing-what-you-sent).

## Coach context and AI actions

Each workspace section's AI button shows its cost on Rezumi AI: fit check 4, briefing, practice feedback or debrief 3, reply or answer draft 2. **Check fit** on a listing in **Jobs** also costs 4; its result is kept, shown again for free until your Profile changes, and copied into **Fit** when you track the job.

**Ask the coach**, or **Coach** in the top bar while a workspace is open, opens application coaching beside the workspace section. The coach receives the job and section context selected for that conversation. You can start another conversation or reopen one from its history.

On any other page, **Coach** in the top bar opens the coach for your whole search in a panel beside the page (a sheet on smaller screens). It stays open as you move between pages. **New conversation** starts another, and **Past conversations** lists earlier ones to reopen, rename or delete. **Open full screen** shows Coach as a page, with your conversations on the left and the chat on the right; **Back to the panel** returns to the panel. Older links to the Coach page open it full screen.

In Coach, context controls include:

| Control          | What it includes when on                                                                                                                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Applications** | Summaries of your applications.                                                                                                                                  |
| **Profile**      | Your Profile's details and career history, active facts, eligible stories and career preferences. The chip counts your facts, for example **Profile · 6 facts**. |
| **Web research** | Lets the coach search the web for public pages; off by default. Search terms go to Rezumi's search service. Needs your own AI connection.                        |

Before each coach web search, review the exact query and select **Search the web** or **Skip**. A proposed story also needs **Save story** approval before it is added to your Profile. These choices work on web and mobile.

Choices persist for that conversation. Earlier messages in the same chat can already contain information shared before a control was turned off.

Workspace buttons such as **Check fit** and **Read it for me** are separate AI actions. Their privacy lines describe their own inputs; chat context choices do not turn those inputs off. They use the default usable AI connection. A schedule can specify a connection; if it is no longer usable, it falls back to the default. [Provider selection](/guides/using-ai#which-provider-is-used) explains this further.

## Schedules

| Kind          | Settings                                                                                                    | Result                                              |
| ------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| **Job alert** | Role, city, country and the search's filters; first run, local time; every day, every 3 days or every week. | Jobs that appeared since the last run wait on Home. |
| **Prepare**   | Interview, AI connection; 24 hours before, 2 hours before or Morning of.                                    | Saved briefing and a notification on Home.          |
| **Remind me** | Application, date and local time.                                                                           | A one-time reminder on Home.                        |

Schedules use the account timezone from **Settings → General**. Morning of means 08:00 on the interview day, or two hours before interviews starting before 10:00. Saving a preparation schedule whose run time has passed makes it due now.

A job alert repeats a search from **Jobs** with the same job data providers, so it needs no key. A new alert starts from the first role and place in **Profile → Preferences** and the country in **Where you're looking for work**, unless it is saved from a search on **Jobs**. Plans set how many alerts can be on at once (Free 1, Plus 3, Pro AI 10); paused ones don't count. When Rezumi limits job searching for the day, a due alert waits until the next day. Other web searches (the coach) target the countries in **Where you're looking for work**: up to three, your account timezone's country until you change it, or none to search anywhere.

Every night Rezumi marks jobs whose postings closed. They leave search results and job alerts, and an application tracked from **Jobs** shows **Posting closed**; one still in **Saved** also gets a notice on Home, once.

An account can keep up to 100 schedules; delete ones you no longer need to add more. The schedule switch pauses work while keeping settings. Editing the interview moves its briefing schedule. Removing an interview pauses related preparation schedules and produces a notice. Recurring searches keep their local time across daylight-saving changes; missed runs are coalesced rather than all replayed.

Interview and schedule forms reject local times skipped by a daylight-saving change. Choose a valid time in the selected timezone instead of accepting an automatic one-hour shift.

Delivery depends on server scheduling and connections. The browser can be closed. **Also email…**, when offered, requires a verified account email and email delivery configured by the administrator. Email copies are optional; in-app notices remain on Home.

Scheduled work runs in the background, so a briefing can arrive a little after its scheduled time.

## Voice

Text feedback uses your selected text AI connection. Reading questions and transcribing answers are separate tasks chosen in **Voice settings**.

| Item              | Limit or behavior                                                                                                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Recording         | Up to two minutes per answer.                                                                                                                                                                    |
| Audio upload      | Nonempty WebM, MP4/M4A, MP3, WAV or Ogg, at most 2 MiB; the interface says 2 MB.                                                                                                                 |
| Read aloud        | A supported speech connection, otherwise the browser's voice where available. Sends the question text.                                                                                           |
| Transcription     | A supported transcription connection, otherwise browser dictation where available.                                                                                                               |
| Browser dictation | Available in supported Chrome, Edge and Safari environments; not Firefox. Permission and platform support still matter.                                                                          |
| Fallback          | **Type** remains available when recording or dictation does not work.                                                                                                                            |
| Transcript        | Check and edit before requesting feedback. Provider transcripts keep original and edited text distinguishable.                                                                                   |
| Raw recording     | Not stored by the Rezumi server. Provider processing follows that provider's policies.                                                                                                           |
| Local audio       | Cleared after successful provider transcription unless you choose to keep it locally for download. A failed transcription keeps it for retry; local audio clears when the answer panel unmounts. |

Speech connections may charge separately from text AI. Browser speech does not use your AI-provider account; the browser maker may process audio for dictation. The page names who handles each action. See [Practice one answer](/guides/preparing-for-interview-day#practice-one-answer).

## Your data

| Action                         | Effect                                                                                                                                                                                                                                                                        |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Correct** a fact             | Keeps earlier text in history and flags linked stories for review.                                                                                                                                                                                                            |
| Switch **Use in coaching** off | Keeps the fact but excludes it from new coaching context.                                                                                                                                                                                                                     |
| **Forget** a fact              | Removes its content and evidence links after the Undo window. Leaves the source resume, message or file alone.                                                                                                                                                                |
| **Use for all applications**   | Promotes an application-private fact to your shared facts.                                                                                                                                                                                                                    |
| Delete a Saved item            | Removes that saved result after the Undo window; does not erase sent employer messages.                                                                                                                                                                                       |
| Export account data            | Includes your Profile (`profile.json`) and, in `career.json`, career preferences, facts and revisions, stories, saved items, workspace data, schedules, notifications, discovery, jobs, stored voice transcripts and career conversations. Provider credentials are excluded. |
| Delete account                 | Removes your dependent career records along with account data. See [Deleting your account](/guides/deleting-your-account).                                                                                                                                                    |

Undo notices for Career deletions and applied message changes last six seconds. Once committed, deletion is not an ongoing trash or restore feature. Exported copies, previously sent material, provider-retained data and installation backups have their own lifetimes.

Your facts, stories and preferences can support Fit, answers, preparation, practice and message reviews as well as Coach. Each AI action names the selected connection and the context it sends. Facts with coaching switched off, forgotten facts, unsupported stories and stories awaiting correction review are excluded from new context.

Unsent Coach messages, story drafts, practice answers and edited recruiter replies survive navigation and refresh within the same browser tab and signed-in account. Successful sends or saves clear the corresponding draft. Browser storage must be available for refresh recovery.

## When something does not work

A failed load shows an error and **Retry**. It does not mean your records are empty or your saved privacy choices have changed. Saved results remain read-only; return **Back to current** before changing a plan or remembering a fact.

| What you see                   | What to check                                                                                                         |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| No AI action is available      | If connections failed to load, use Retry. Otherwise connect and test a provider in Settings; choose a usable default. |
| An AI request fails            | Read the error; check the connection, model access and provider quota. Saved work remains available.                  |
| Prepare asks for an interview  | Add the relevant round under Next step → Edit.                                                                        |
| A saved result is read-only    | Choose Back to current before editing.                                                                                |
| No new roles from a job alert  | Check whether the alert is on and when it runs next. A run can find no new openings, especially for narrow searches.  |
| A briefing or reminder is late | Check timezone and schedule state.                                                                                    |
| Email copies do not arrive     | Verify your address and check installation email configuration. Look on Home for the in-app notice.                   |
| Microphone is blocked          | Allow it for this site in browser settings, choose an audio file where available, or type.                            |
| Transcription failed           | Retry the current recording or type; check the chosen speech connection.                                              |
| A claim is wrong               | Edit the draft and correct its source fact. Review linked stories and rerun affected AI work when needed.             |
