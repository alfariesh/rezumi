**Jobs** searches current openings for you. Listings come from job data providers that collect postings from company careers sites and job boards, so you don't need an account with them or any key or connection in Rezumi. Each listing links to its original posting, which is the one to apply through.

To open it, select **Jobs** in the sidebar, just above **Applications** (on a phone, open the menu at the top left first).

## Search

The first time you open **Jobs**, the search starts from your [preferences](/guides/building-career-knowledge): the first role you want, the first place, and the country your searches target (**Where you're looking for work**; otherwise your account timezone's country). Nothing is searched until you select **Search**. If you have target roles, they show as buttons that search for that role straight away.

1. Type a role or keywords. Job titles work best: "data analyst" finds data analyst jobs, while a skill such as "python" finds only jobs with it in the title.
2. Add a city if you want one place inside the country, or leave it empty for the whole country.
3. Choose the country, or **Anywhere**.
4. Select **Search**.

Changing a filter doesn't search by itself. Set everything you want, then select **Search**.

| Filter                                     | Choices                                                                                                                                                                                                                |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Posted**                                 | The last day, week, two weeks or 30 days (the default).                                                                                                                                                                |
| **Work arrangement**                       | On-site, hybrid or remote (the default); **Remote in this country** with a country chosen, **Remote anywhere** with **Anywhere**; **Hybrid**; **On-site**.                                                             |
| **Level**                                  | Any level, or entry, junior, mid, senior, lead or executive.                                                                                                                                                           |
| **More filters → Minimum yearly pay**      | An amount and currency (it starts with the country's). **Include jobs that don't list pay** is on, because many postings don't list pay, especially outside the US; turn it off to see only jobs that list enough pay. |
| **More filters → Offers visa sponsorship** | Only jobs whose listing says it sponsors a visa. Few listings say either way, so this narrows results a lot.                                                                                                           |

Results come 20 at a time; select **Load more** under them for the next ones. The line above the results says how many there are and when they were fetched. Rezumi keeps search results for a few hours and shares them between everyone who searches the same thing, so a search can show listings fetched earlier.

## Searches each day

Free includes 3 searches a day, Plus 15 and Pro AI 40. Each search counts, and so does each **Load more**. Opening the same search again on the same day doesn't count again. The top right of the page shows how many are left. When they're used up, results you already opened stay available, and searches start again at midnight in your account timezone. See [Plans and payments](/guides/plans).

Sometimes Rezumi limits new searches for everyone for the rest of the day. The page then says so and shows results saved earlier where there are some.

## Read a listing

Select a listing's title to read it in full beside the results (from the bottom on a phone): the description, what the job asks for, skills, and the company's industry and size when the provider has them. Listings show the provider's text as it was published, so check the original posting before you apply.

Each listing shows what it states: how it's worked, the listed pay in its own currency, **Visa sponsorship**, the level, when it was posted and where it was found ("via LinkedIn", or "via the company's careers site").

## Track a job or tailor a resume

| Button            | What it does                                                                                                                                                                                                                                                          |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Track**         | Saves the job in [Applications](/guides/tracking-job-applications) as **Saved**, with the role, company, place, listed pay, the provider's copy of the description and the link to the original posting. The button becomes **Tracked**, which opens the application. |
| **Tailor resume** | Tracks the job if you haven't, then opens [tailoring a resume for it](/guides/tailoring-a-resume-for-a-job).                                                                                                                                                          |
| **View original** | Opens the original posting in a new tab.                                                                                                                                                                                                                              |

A job you already saved, from here, from a link or with the [browser extension](/guides/saving-jobs-from-your-browser), shows as **Tracked**; tracking it again doesn't make a second application.

To take a listing out of your results, open its **⋯** menu and select **Hide this job**. The notice offers **Undo**.

## When nothing matches

- Choose a longer posting window, fewer filters or other words. Job titles work better than skills.
- Try **Anywhere** with **Remote anywhere** for remote work.
- For local job boards the providers don't cover, save jobs from your browser with the [browser extension](/guides/saving-jobs-from-your-browser), or paste a link in **Save job** on Applications.

If jobs can't be loaded, try again in a moment. Results you already opened stay available.
