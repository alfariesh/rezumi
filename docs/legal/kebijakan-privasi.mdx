## Penerima data

- **Cloudflare:** Worker, jaringan, pengamanan dan penyimpanan unggahan privat di R2; termasuk metadata permintaan.
- **Neon:** basis data PostgreSQL terkelola untuk akun, dokumen dan catatan layanan. Wilayah basis data/backup: **[KONFIRMASI PEMILIK]**.
- **Polar (Polar Software, Inc., Amerika Serikat):** penjual resmi (_Merchant of Record_) langganan. Saat checkout, Rezumi mengirim
  id akun, nama, email, alamat IP (untuk mata uang dan lokasi pajak) dan bahasa; pelanggan mengisi data pembayaran dan alamat tagihan
  langsung di Polar. Polar memproses pembayaran (melalui Stripe), pajak, invoice, dan sengketa sebagai pengendali data sendiri menurut
  kebijakan privasinya. Rezumi menerima id dan status order/langganan/refund, nilai dan periode; tidak menerima atau menyimpan nomor kartu,
  CVC, atau alamat tagihan. Saat akun dihapus, Rezumi meminta Polar menghapus dan menganonimkan data pelanggan; Polar menyimpan catatan order
  sesuai kewajiban hukumnya. Data dapat diproses di luar Indonesia.
- **Provider AI:** hanya data yang diperlukan untuk tindakan yang diminta, seperti teks CV/surat, lowongan, jawaban, knowledge atau konteks percakapan.
  BYOK memakai provider yang dipilih (mis. OpenAI, Anthropic, Google Gemini, OpenRouter atau endpoint kompatibel).
  Rezumi AI akan menunjukkan provider/model sebelum digunakan; **provider peluncuran, lokasi dan retensinya belum diputuskan**.
  Pemakaian kredit tidak berarti izin memakai data untuk melatih model. Ketentuan retensi/pelatihan provider harus disampaikan sebelum aktivasi;
  jangan aktifkan Rezumi AI sebelum informasi tersebut lengkap. API key tersimpan dienkripsi, bukan ditampilkan ke pengguna lain.
- **Email transaksional:** alamat email, informasi akun atau rincian bukti bayar yang diperlukan; provider/retensi produksi **[KONFIRMASI PEMILIK]**.
- **Login sosial dan aplikasi terhubung:** provider login menerima permintaan autentikasi. Aplikasi OAuth/API/MCP yang diizinkan dapat membaca/mengubah
  profil, CV, surat, lamaran, riwayat/statistik dan data karier sesuai scope. Cabut izin lewat pengaturan aplikasi terhubung/API key.
  Setelah diterima, data mengikuti kebijakan pihak itu; pencabutan menghentikan akses berikutnya, tidak otomatis menghapus salinan terdahulu.
- **Penerima publik:** CV yang dipublikasikan dapat dilihat/disalin sesuai pengaturan tautan dan password; mesin pencari dapat menyimpan salinan bila diizinkan.
  Gambar/font eksternal membuat permintaan ke host terkait. Hukum dapat mewajibkan pengungkapan terbatas kepada otoritas.

PDF editor web dirender di browser dengan Forme; preview/ekspor PDF mobile dirender di perangkat.
PDF publik/API dirender oleh server sendiri. ATS checker publik memproses PDF di browser tanpa mengunggah file.
Sinkronisasi, pemeriksaan/ekspor lain dan AI dapat mengirim konten ke server sesuai fungsi yang digunakan.

## App mobile dan izin

Token login memakai penyimpanan aman sistem. Penyimpanan privat app memuat preferensi, draf, cache dokumen/font/gambar dan ekspor.
Picker foto sistem digunakan; kamera hanya ketika mengambil foto. Mikrofon hanya saat merekam latihan wawancara.
Transkripsi mengirim audio melalui server ke provider pilihan; suara buatan mengirim teks ke provider suara. Ini bukan pemrosesan suara lokal.
Pengaturan Keep audio mengendalikan salinan lokal, bukan retensi provider. Izin kamera, mikrofon dan notifikasi dapat dicabut lewat sistem.
Pengingat menggunakan notifikasi lokal; app tidak mendaftarkan push jarak jauh.

Mobile meminta persetujuan data sebelum tindakan AI; menolak membatalkan tindakan. Mengaktifkan jadwal karier mengizinkan proses berulang
sesuai pengaturannya sampai dimatikan. Laporan AI/CV publik hanya mengirim konten, kategori dan penjelasan yang Anda pilih,
identitas akun serta waktu peninjauan ke operator, bukan provider AI. Laporan ikut ekspor akun dan dihapus bersama akun atau lebih awal setelah ditinjau.
Pemblokiran penulis CV disimpan lokal per akun/server dan tidak menghapus konten web atau perangkat lain.

## Retensi dan penghapusan

Data akun, dokumen, unggahan dan versi disimpan selama diperlukan untuk layanan sampai dihapus pengguna/akun.
Trash dihapus permanen setelah 30 hari kecuali dipulihkan atau dihapus lebih awal. Izin aplikasi dan token disimpan sampai dicabut,
kedaluwarsa atau akun dihapus. Penghapusan akun tersedia di **Settings → Account → Delete account**; mobile membuka konfirmasi browser
server dan dapat meminta login ulang. Menghapus instalasi app tidak menghapus akun. Bersihkan file ekspor dan cache perangkat bila diperlukan.

Setelah akun dihapus, hubungan identitas pengguna pada catatan pembayaran dilepas/dianonimkan; jangan menyebut catatan masih anonim bila dapat dihubungkan kembali.
Catatan pembukuan transaksi yang tidak mengidentifikasi pengguna direncanakan disimpan **10 tahun [KONFIRMASI KEWAJIBAN DAN SKEMA OLEH PEMILIK/KONSULTAN]**.
Jika hukum mengharuskan bukti beridentitas tertentu, hanya bagian yang wajib dipisahkan, aksesnya dibatasi dan dasar serta masa simpannya dijelaskan.
Kewajiban hukum atau sengketa dapat menunda penghapusan data terkait dengan alasan yang diberitahukan.
Retensi log, tiket dukungan, ledger AI, backup dan siklus penghapusan backup: **[BELUM DITETAPKAN PEMILIK SEBELUM PUBLIKASI]**.
Tidak ada janji penghapusan instan dari seluruh backup/provider; penyelesaian permintaan dan sisa retensi dijelaskan kepada pengguna.

## Hak dan permintaan data

Anda dapat meminta informasi pemrosesan, akses/salinan, perbaikan, penghapusan/pemusnahan, penarikan persetujuan,
penghentian/pembatasan pemrosesan, portabilitas sesuai syarat hukum, keberatan atas keputusan otomatis yang berdampak signifikan,
dan mengajukan pengaduan/ganti rugi. Rezumi tidak menjanjikan keputusan perekrutan otomatis.
Ekspor akun dan pengeditan tersedia di app; permintaan lain melalui email di atas. Verifikasi identitas dilakukan secara proporsional.
Penarikan persetujuan berlaku untuk pemrosesan berikutnya; kewajiban hukum dapat tetap memerlukan retensi terbatas.
Kami menangani akses, perbaikan, penghentian atas penarikan persetujuan dan pembatasan dalam **3 × 24 jam** bila UU PDP menetapkan tenggat itu,
serta mengikuti tenggat khusus hak lain. Bila permintaan dibatasi oleh hukum, kami menjelaskan alasan dan jalur keberatan.
