# Portfolio sample wordmarks

These lossless WebP images are the complete fictional company logos from [Untitled UI](https://www.untitledui.com/resources/logos). The fixtures use the original names, graphics, and colors.

Sources are under `https://www.untitledui.com/images/logos/default/light/`. Files ending in `-dark.webp` come from the same filenames under `default/dark/`.
